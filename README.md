# Лабораторна робота 5 — шифрування на JavaScript

Реалізовано всі чотири завдання з документа «Лаб №5 – 2026.docx».
Програма працює у Node.js 22 або новішому. Використано лише вбудовані модулі;
встановлювати пакети через `npm install` не потрібно.

## Запуск

Розпакуйте архів і відкрийте термінал у папці `lab5_encryption`.
Виконайте всі завдання:

```bash
node lab5.js
```

Для Віженера типовим ключем є `Молитовник`. Щоб задати своє прізвище:

```bash
node lab5.js all "ВашеПрізвище"
```

Завдання можна запускати окремо:

```bash
node lab5.js 1
node lab5.js 2 "Молитовник"
node lab5.js 3
node lab5.js 4
node lab5.js 4 "Власний український текст 🔐"
```

Кожен файл завдання також запускається самостійно:

```bash
node task1_caesar.js
node task2_vigenere.js "Молитовник"
node task3_rsa_number.js
node task4_rsa_text.js
```

У Windows ці команди працюють у PowerShell, CMD та Git Bash.

## Завдання 1 — шифр Цезаря

Для латинського алфавіту використано формули `C = (P + k) mod 26` та
`P = (C - k + 26) mod 26`. Регістр зберігається; інші символи не змінюються.

`bruteForceCaesar` повертає всі 26 варіантів, включно з ключем 0.
Для `vppanlwxlyopyncjae` змістовний результат — `keepcalmandencrypt`, ключ **11**.
У демонстрації ця впізнана фраза відбирається з результатів перебору;
універсального автоматичного визначення мови програма не виконує.

## Завдання 2 — шифр Віженера

Алфавіт містить 33 літери:

```text
абвгґдеєжзиіїйклмнопрстуфхцчшщьюя
```

Шифрування: `C_i = (P_i + K_i) mod 33`.
Дешифрування: `P_i = (C_i - K_i + 33) mod 33`.
Ключ повторюється циклічно. Пробіли, цифри, пунктуація та символи поза
українським алфавітом зберігаються й не витрачають літери ключа.
Регістр українських літер також зберігається.

В умові рядок `криптографічнiметодизахистуінформації` містить латинську `i`.
У демонстрації `normalizeUkrainianText` окремо замінює її на українську `і`:
`криптографічніметодизахистуінформації`.
Перевірка порівнює дешифрований текст із цим нормалізованим рядком.
Самі функції шифрування і дешифрування не нормалізують відкритий текст автоматично.

Ключ задавайте прізвищем українською. У ключі ігноруються пробіли, апострофи та дефіси.

## Завдання 3 — RSA для M = 100

Програма генерує різні прості числа `p` і `q` через `crypto.generatePrimeSync`.
Далі обчислює:

```text
n = p * q
phi(n) = (p - 1) * (q - 1)
e = 65537, gcd(e, phi(n)) = 1
d = e^(-1) mod phi(n)
Відкритий ключ: (e, n)
Закритий ключ: (d, n)
C = M^e mod n
M = C^d mod n
```

За замовчуванням `p` і `q` мають по 32 біти для наочного навчального прикладу
RSA без padding. Арифметику RSA реалізовано вручну з `BigInt`; генерація простих
чисел використовує вбудований модуль. Малі навчальні ключі не призначені для захисту реальних даних.
Значення записуються як `100n`, щоб не втрачати точність.
Повідомлення та шифротекст повинні задовольняти `0 <= значення < n`.
Числа, ключі та шифротекст змінюються при кожному запуску; результат дешифрування — **100**.

## Завдання 4 — RSA для UTF-8 і Base64

Використано RSA із модулем 2048 біт та OAEP із SHA-256 через вбудований `node:crypto`.
Окремі функції виконують кожний етап:

1. Рядок перетворюється на байти UTF-8.
2. Байти діляться на блоки по `k - 2*hLen - 2`, тобто по 190 байт для цього ключа.
3. Кожен блок шифрується відкритим RSA-ключем у блок із 256 байт.
4. Зашифровані блоки об'єднуються та кодуються у Base64.
5. Під час дешифрування Base64 повертається в байти та ділиться на блоки по 256 байт.
6. Блоки дешифруються закритим ключем; усі відкриті байти об'єднуються.
7. Об'єднані байти декодуються в початковий UTF-8 рядок.

Поділ на блоки усуває обмеження довжини одного RSA-повідомлення.
Підтримується довільна довжина в межах доступної пам'яті та лімітів `Buffer` Node.js.
UTF-8 декодується після об'єднання блоків, тому навіть символ, байти якого
розділені між двома блоками, відновлюється правильно.
Підтримуються українська, латиниця, інші мови, emoji, переноси рядків,
нульові байти, BOM та порожній рядок.
Порожній текст представляється порожнім Base64 рядком.

Перевіряється точний рядок з умови:

```text
Cryptography is fun and educational! Learning RSA encryption and decryption with Python helps understand public key cryptosystems.
```

Слово `Python` є частиною заданих даних; уся реалізація написана на JavaScript.
Демонстрація додатково перевіряє український текст з emoji.
Ключі генеруються при кожному запуску й залишаються в пам'яті.
Для дешифрування потрібен закритий ключ саме тієї пари, якою зашифровано текст.

OAEP додає випадковість, тому шифротекст одного повідомлення відрізняється
між запусками. Base64 — лише формат подання зашифрованих байтів.
Формат із послідовних RSA-блоків є навчальним і не автентифікує порядок
чи кількість блоків цілого повідомлення.

## Використання функцій у власному коді

```javascript
const { encryptVigenere, decryptVigenere } = require('./task2_vigenere');
const { generateRsaNumberKeys, encryptRsaNumber, decryptRsaNumber } = require('./task3_rsa_number');
const { generateRsaTextKeys, encryptRsaText, decryptRsaText } = require('./task4_rsa_text');

const encryptedWord = encryptVigenere('Україна', 'Молитовник');
console.log(decryptVigenere(encryptedWord, 'Молитовник'));

const numberKeys = generateRsaNumberKeys();
const encryptedNumber = encryptRsaNumber(100n, numberKeys.publicKey);
console.log(decryptRsaNumber(encryptedNumber, numberKeys.privateKey).toString());

const { publicKey, privateKey } = generateRsaTextKeys();
const encryptedText = encryptRsaText('Привіт, світе! 🔐', publicKey);
console.log(encryptedText);
console.log(decryptRsaText(encryptedText, privateKey));
```
